01 / System architecture

From local learning to trusted consensus

Each hospital trains locally. A committee validates candidate updates, and accumulated node reputation informs subsequent committee selection.

🏥

Hospital nodes

Local data remains at participating nodes in the simulation.

🧠

Local training

Generate candidate model updates and round-level scores.

🛡️

Validation

Committee checks updates with Byzantine-robust logic.

📈

Reputation

Accumulate behavior evidence with asymmetric updates.

🔗

Election

Rank eligible nodes to select future committees.

COMPONENT 01

BFLC-style committee consensus

Committee validation and federated aggregation, based on the referenced 2021 IEEE Network work.

COMPONENT 02

BtRaI reputation model

Credibility-weighted reputation with penalties that can be stronger than rewards.

COMPONENT 03

Integrated simulator

Compares score-based election, reputation-based election and forced-rotation controls.

04 / Reproducibility

Run the actual research software

The uploaded package includes source modules, examples, tests and documentation. The commands below execute the actual Python implementation locally.

STEP 01

Install

python -m pip install -e ".[dev]"

Run from the project root with Python 3.10+.

STEP 02

Execute examples

python examples/demo_sleeper_attack.py
python examples/demo_reputation_dynamics.py
STEP 03

Verify tests

python -m pytest tests/ -v

The patched package contains 64 tests; this website does not execute them.

Implementation scope and limitations

MedChain is a Python research simulator. It does not implement BtRaI token incentives, integrate with a production blockchain, provide a web-connected backend, or handle real patient data. The dashboard is a static explanatory layer; reported numerical outcomes should be verified against a fresh local run.
